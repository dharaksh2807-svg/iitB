Reproducibility & Verification Environment

Fully Reproducible

Hardware & Software Stack

  • Target Hardware: Apple Silicon M5 (Unified Memory Architecture)
  • Compute Backend: PyTorch 2.14.1 with Metal Performance Shaders (MPS)
  • Base Model: Qwen/Qwen2.5-1.5B-Instruct (1.54B Parameters)
  • Precision: BFloat16 (eager attention) & Float16
  • Context Windows Tested: 1,024, 2,048, and 4,096 tokens
  • Decoding Strategy: Greedy argmax ($\tau=0.0$, deterministic)
